# Запуск 
1. Скачайте `requirements.txt` и `main.py`.
2. Установите Python версии 3.11 или выше
3. Перед запуском установите все зависимости из файла requirements.txt:
```pip install -r requirements.txt```
4. Измените `BOT_TOKEN` и `ADMIN_ID` на свои
5. Запустите главный файл командой:
    ```python3 main.py```

# Использование 
Загружать ресурсы в бота может только пользователь, ID которого введён в ADMIN_ID.

1. Для загрузки файлов отправьте команду `/add`.
2. Затем нужно ввести 4-х значный уникальный код.
3. Выбрать тип ресурса `build`, `plugin`, или `other`
4. Ввести Название ресурса
5. Ввести Описание ресурса (можно оставить пустым, отправив skip)
6. Ссылку на ресурс (можно оставить пустым, отправив skip)
7. Сам файл ресурса в телеграм (можно оставить пустым, отправив skip)
8. Картинку для поста (можно оставить пустым, отправив skip)
9. Ваш ресурс сохранён!

Посмотреть количество скачиваний ваших ресурсов можно с помощью /stats.

# Монетизация
Для того, чтобы пользователи могли скачать ресурс, они должны быть подписаны на 2 канала (можно сделать больше, меньше, или вообще убрать). ID этих каналов нужно ввести в `main.py`, также добавить бота в каналы как администратора.

Вместе с ресурсом пользователь получает рекламное сообщение. Его можно отредактировать в `AD_TEXT`. Под рекламным сообщением есть инлайн-кнопка, направляющая на рекламируемый продукт. Её можно изменить в `kb_ad`. 

Также рекламное сообщение можно разослать всем пользователям с помощью команды `/sendads`

Можно рассылать любые другие сообщения всем пользователям с помощью `/sendmessage`
